# 更新入口按需显示

Windows 与 macOS 共用设置底栏及原生检查接口。

## 行为

- 打开设置后后台检查远端版本；检查中、无新版、仓库未配置或检查失败时，只显示本地版本号。
- 当前平台有可用新版时，显示「下载更新」；不额外显示自动更新说明或“已是最新版”。
- 点击后沿用既有下载安装流程，显示进度、必要的错误和重试入口；Mac 等待任务结束时仍可取消等待。
- 设置保持打开时每 15 分钟复查；返回窗口时可复查（间隔至少一分钟），网络恢复后重试。
- 后台检查只请求更新清单，不下载或安装；它的 30 秒超时不传给用户触发的下载。
- 旧仓库的迟到响应不会显示按钮；用户开始更新后，旧的后台检查和状态请求不能覆盖当前进度。

## 验证

- 263 项设置测试通过，包括静默检查、新版按钮、失败重试、切换仓库、重复点击和异步状态竞争。
- 10 项原生 updater 回归通过；macOS 原生代码编译通过。
- 生产及测试 TypeScript 检查、前端构建通过。
- 真实设置页的隔离浏览器预览验证了无新版、有新版和检查失败三种状态。
- 本轮尚未生成安装包或公开发布；Windows 原生构建和两端实机交互留待下一次打包验收。
