# 本地文件与媒体附件

聊天窗口使用 Tauri 原生拖拽事件取得文件或文件夹路径。前端接收已注册资源的 ID 和展示信息，不再把文件夹当作大小为零、没有 MIME 的浏览器 `File`。

## 原生选择与待发送预览

聊天加号使用 Tauri 原生多选，选择器打开时防止重复选择和发送；取消保留草稿及已有附件，会话或目录切换后的迟到选择结果丢弃。普通附件字节读取复用受限 picker：仅 chat 窗口可调用，返回文件名和内容而非任意路径读取权限，普通文件 20 MiB、NCM 64 MiB、单批总量 64 MiB；暂存层继续检查格式、会话配额和 NCM 本地转换。音视频原生资源选择走资源登记与下文的引用/复制边界，不套用整文件 Base64 读取流程。

待发送附件区位于输入框边框外，使用当前主题的不透明底色。GIF、PNG、JPEG、WebP 使用暂存检查后的原始字节显示缩略图，GIF 保留动画；文件名、大小/状态及可访问的移除操作保留。解码失败回退文件信息，多附件在有高度上限的区域换行滚动。缩略图随移除、会话重置或发送完成释放，实际发送读取暂存源，不依赖预览。

独有原生 QA 回执保存在[选择器修复](archive/attachments/chat-attachment-picker-fix.md)和[图片预览](archive/attachments/chat-attachment-preview.md)历史记录；模型收到原始图片请求不等于真实视觉模型理解已经验收。

## 支持范围

| 类型 | 接收格式 | 预览 |
| --- | --- | --- |
| 音频 | MP3、WAV/WAVE、M4A、AAC、FLAC、OGG/OGA、Opus、AIFF/AIF、WMA | 系统 WebView 的音频播放器，可播放、暂停和拖动进度 |
| 视频 | MP4、M4V、MOV、WebM、MKV、AVI、OGV、MPEG/MPG | 系统 WebView 的视频播放器，可播放、暂停和拖动进度 |
| 文件夹 | 原生目录 | 展开查看最多 100 个直接子项 |
| 图片、文档、NCM | 原有支持格式 | 普通聊天继续使用原有附件处理流程 |

接收某个文件格式不代表系统支持其中所有编码。媒体无法播放时显示错误信息，附件卡片仍然保留。没有增加自动转码依赖。

工作区聊天同样接收本地资源。拖入文件夹表示附加该目录，不会把它设为当前工作区；切换工作区继续使用输入框里的文件夹选择器。

## 发送与生命周期

- 原生拖入音视频只注册引用，不通过 IPC 复制整个文件，也不把音视频 Base64 塞入模型请求。
- 文件夹复用 OpenCode `application/x-directory` 的 `file://` 附件能力。图片、PDF、文本在工作区聊天中可使用相应原生文件 part。
- 音视频传给模型的是本地工具资源说明。预览成功不代表模型理解了音轨或画面；转写、抽帧或内容分析仍需要适用的工具及模型。
- 剪贴板和浏览器 `File` 没有可信原生路径，音视频会保存为应用自己的副本，单个副本限制为 64 MiB。原生文件引用没有此复制限制。
- SQLite 注册表保存资源与会话、原生消息 ID 的对应关系。重新打开消息时恢复附件卡片。
- 原生资源指向原文件，原文件被移动或删除后需要重新添加。它不是内容快照。
- 移除草稿、切换会话或关闭聊天会释放未发送的引用及应用自己的上传副本。已发送的引用保留至删除会话。以上操作不会删除用户选择的原文件。

## 边界

资源只能来自原生选择器、原生拖拽，或受限的媒体上传。预览协议只接受已注册的不透明资源 ID，限定在聊天窗口；不能传任意路径。音视频支持字节范围读取，每次 Range 响应最多 2 MiB。没有 Range 的完整媒体响应最多 64 MiB，图片最多 20 MiB。

读取权限绑定目录和会话。单个文件授权不包含兄弟文件，目录授权检查实际路径，越界符号链接不能扩大范围。包含符号链接或超过检查上限的目录不自动授权递归搜索，可按需读取目录和具体文件。附件不会授予写入或执行权限。

## 验证入口

- `src/chat/localResources.test.ts`：格式识别、IPC 元数据和预览 URL 边界。
- `src/chat/useLocalResources.test.tsx`：晚到结果、跨会话隔离、并发拖入和草稿清理。
- `src/chat/nativeResourceFlow.test.tsx`：普通聊天、工作区发送、历史预览、失败重试。
- `src/chat/MediaPreview.test.tsx`、`LocalResourceTray.test.tsx`：媒体控件、目录内容、错误提示。
- `src-tauri/src/chat_attachments/resources/tests.rs`：注册表持久化、范围读取、权限和原文件保护。

真实播放器验收需要重新运行含 Rust 改动的桌面应用，分别拖入实际的 MP3、WAV、MP4 和文件夹，检查播放、进度跳转、发送以及重开历史。组件测试不能替代 WebView 编码兼容性验收。
