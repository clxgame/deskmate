# YUME v0.4.12

## 修复

- 修复聊天输入区加号无法选文件：与工作台共用原生文件选择器，支持多选，取消保留草稿和附件，所选内容进入实际模型请求。
- 空白会话不再显示在历史、搜索、归档或会话数量中；旧空线程在成功刷新后自动排除。已发送但未回复、附件消息、工具消息和 Agent 任务均保留。底层临时上下文继续可用，不影响模型选择或首次发送。
- 会话历史跟随深色、蜜桃、薄荷、薰衣草主题，统一底色、搜索、筛选、菜单、选中状态及键盘焦点。

- 类型检查和原生 QA 构建通过。

- Rust 历史 94 项、原生附件选择读取 2 项通过；HTTP/SSE 测试在允许本机监听的环境运行。
