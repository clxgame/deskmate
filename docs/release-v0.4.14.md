# YUME v0.4.14

## 更新内容

- 聊天支持拖入文件夹、音频和视频。音视频附件带本地预览播放器；文件夹可展开查看内容。已发送的资源在聊天历史中恢复预览。
- 本地资源按会话授权读取。草稿移除和会话删除会清理应用自己的临时副本，不会删除原文件。
- 自动整理聊天记忆与工作进展，并在设置中管理处理状态和重试失败任务。记忆与日志在本机保存，沿用各自的启用设置。
- 清理聊天中的固定记忆和工作日志操作，将相关功能移入自动处理流程与设置页。

## 格式与边界

音频接收 MP3、WAV、M4A、AAC、FLAC、OGG/OGA、Opus、AIFF/AIF、WMA；视频接收 MP4、M4V、MOV、WebM、MKV、AVI、OGV、MPEG/MPG。是否能播放取决于系统 WebView 支持的编码。拖入和预览本身不会转写音频或分析视频内容。

自动记忆的语义准确度尚未用真实模型服务做完整验收。首次使用请在设置中确认自动处理开关；可以查看处理状态并重试失败项。

## macOS 发布状态

Mac 安装包须先由维护者使用 Apple Developer ID 本地签名并完成公证。GitHub Actions 产生的未签名候选包不是安装包，也不能作为公开下载。
