# YUME v0.4.16

## 更新内容

- 在「设置 → 小组件」新增「今日星运」，可查看当天最旺星座和全部十二星座的综合、事业、爱情、财运、活力、宜忌、幸运色与幸运数字。
- 可选择或清除「我的星座」，快速查看个人星运；偏好保存在原有设置中，不需要生日、账户或网络请求。
- 运势按设备当地日期和固定生成版本计算，同日结果保持一致；跨午夜、应用恢复可见及系统日期变化时更新。
- 新界面和内容支持简体中文、英语、日语、韩语，并沿用现有四种主题。

## 验证

- 星运数据、日期刷新、设置交互与受影响小组件的 47 项前端测试通过；macOS 发布保护测试 12 项通过。类型检查和前端构建通过。
- 已在两种设置窗口尺寸、四种语言和四种主题下检查布局与键盘焦点；macOS 调试版验证了个人星座保存后重开仍能读回。
- 完整前端测试集仍有基线已有的失败；逐项对照原始 v0.4.15 源码，没有本次新增的失败。详细记录见 [今日星运实施方案](daily-horoscope-implementation-plan.md#12-首版实施验证记录2026-09-30)。
