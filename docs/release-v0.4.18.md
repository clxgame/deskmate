# YUME v0.4.18

## 更新内容

- 修复聊天窗口的文件夹和模型选择菜单丢失主题、字体及背景的问题，菜单现在随当前主题显示，并避开整个输入区域。
- 优化模型名称的显示宽度，长名称保留末尾识别信息；菜单支持内部滚动，在窗口缩放后保持位置和边界正确。
- 修复运行状态持久化失败后的恢复处理，避免重复提交模型请求；历史投影失败时继续处理原生权限和任务终态。
- 加强记忆库首次打开、并发访问和迁移失败的处理，迁移使用事务回滚，拒绝未知的未来数据库版本。
- 更新维护文档与资源生成规则，完整源码检查和工作台重建成为发布构建的前置检查。

## 验证

- 文件夹与模型菜单已在四种主题、多种窗口尺寸、长名称和多模型搜索场景下验证，包含键盘选择、焦点返回与外部点击关闭。
- 本机完整检查通过：类型检查、155/155 个前端测试文件（1,190 pass、0 fail、0 skip）、Rust library 测试（777 pass、0 fail、12 个需专用环境的 ignored）及前端构建。两平台源码检查与工作台重建由本次 GitHub Actions 执行。
- macOS 安装包按发布指南完成 Developer ID 签名、公证和归档校验，并使用隔离更新源验证打包应用的一键升级。具体结果保存在本次发布验收记录中。
- Windows 实际桌面 UI、真实模型语义及物理多显示器回归仍以现行验收待办为准，构建和单元测试不代替这些实测。
