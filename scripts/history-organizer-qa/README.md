# History organizer visual fixture

Run `npm run dev -- --host 127.0.0.1` and open `/scripts/history-organizer-qa/index.html?theme=peach&lang=zh-CN`. This page renders the production history component with 46 synthetic catalog rows and distinct synthetic previews. It never reads or mutates user history. Change `theme` to `dark`, `mint`, `peach`, or `lavender`, and `lang` to `zh-CN` or `en-US`. Check the page at 420 × 560 and 720 × 760 CSS pixels.
